Capa Dominio

Define que puede hacer la aplicación
Define que datos que pueden pasar por la BD

Capa Infraestructura
Conexiones entre la BD y la lógica
Implementan puertos del dominio
Manejan librerías y frameworks externos

Capa de Dominio (Los Planos de la Aplicación)

Esta capa es el núcleo de todo. No sabe de bases de datos ni de APIs. Solo define las reglas del juego: 
qué se puede hacer con cada parte de nuestra aplicación (Barrios, Usuarios, etc.) y qué información se 
necesita para hacerlo. Es como el plano que le pasamos a los trabajadores.


TypeORM permite trabajar con clases y objetos en lugar de escribir consultas SQL manuales.
Cada clase representa una tabla, y cada instancia de esa clase representa una fila (registro) en la base de datos.


Controller

Recibe peticiones por http
Hace una primera validación
Recibe el error y lo muestra entendible


Entities

Entidades de las bases de datos

Routes

Maneja ls direcciones de cada servicio

middleware
